Obsidianを、
普通のブラウザで。

自分の obsidian.asar(Obsidian 1.14.4で検証)を、Electronアプリではなくブラウザで開くためのラッパーです。使い方に合わせて、サーバー版と静的サイト版の2つがあります。スマホ版Obsidianの public フォルダ(APK / IPA から取り出したもの)にも対応しています。

2つの版の違い

サーバー版 obsidian-web-dynamic/静的サイト版 obsidian-web-static/
必要なものPython 3(標準ライブラリのみ)静的ファイルの配信だけ(HTTPS または localhost)
vault(ノートの場所)サーバーを動かすマシン上のフォルダブラウザで選んだPCのフォルダ(またはブラウザ内)
Obsidian本体起動時に --asar で指定し、サーバー側で展開ランチャーが読み込み、ブラウザ内に保存
対応ブラウザ一般的なブラウザ(検証はChromium)フォルダ選択はChrome/Edgeなどデスクトップ版のChromium系のみ
別のPC・スマホから可(トークン付きURL + トンネル等)ホスト先を開くだけ。ただしフォルダ選択はデスクトップChromiumのみ
外部変更の検知約1.5秒ごとにポーリング約4秒ごと + フォーカス復帰時
向いている用途手元・自宅サーバーで安定して使うサーバーを立てたくない、PCのフォルダをそのまま使いたい

サーバー版

Electronのメインプロセス相当をPythonで置き換えます。

cd obsidian-web-dynamic
python server.py --asar obsidian.asar --vault ./MyVault

表示された http://localhost:8765/?token=... をブラウザで開きます。

  • 初回だけ asar を .obsidian-web/app に展開します。2回目以降は --asar は不要です。
  • --vault のフォルダがなければ作成し、サンプルノートを入れます。
  • トークンは .obsidian-web/token に保存され、再起動後も同じURLが使えます。
  • スマホ版の public フォルダのzipを server.py と同じフォルダに置く(または --mobile-zip で指定する)と、スマホ・タブレットにはモバイル版、PCにはasar版を同じURLで出し分けます。?ui=mobile / ?ui=desktop で強制もできます。
  • オプション: --port --host --cache --verbose --mobile-zip --allow-host

構成

server.py(静的配信 / 同期IPC / vault内限定のファイルAPI / 画像配信)と、web/shim.js(require('electron') や fs・path などのブラウザ代替)、web/mobile-shim.js(スマホ版用の代替)でできています。

セキュリティ

  • 既定では 127.0.0.1 のみで待ち受けます。Hostヘッダ検証、トークンCookie(SameSite=Strict)、独自ヘッダで、他サイトからの操作を拒否します。
  • ファイル操作はvault内に限定されます(シンボリックリンクでの脱出も拒否)。
外部に公開するとき 0.0.0.0 で公開する場合は、必ずSSHトンネルか、HTTPS付きのリバースプロキシ越しにしてください。

静的サイト版

サーバーなしで、ファイルを置くだけで動きます。本体の読み込みはService Workerとブラウザ内展開、ファイル操作はFile System Access APIで行います。

https://nattomaki10000.github.io/obsidian-web/obsidian-web-static/ で、インストールせずに試せます。

cd obsidian-web-static
python -m http.server 8800      # → http://localhost:8800/

ランチャー(index.html)で、①本体を読み込む → ②フォルダを選ぶ → ③開く、の順に進めます。

Obsidian本体の渡し方

アップロード不要にもできます。ランチャーは、開いた端末に合わせてPCにはデスクトップ版(asar)、スマホ・タブレットにはモバイル版(public フォルダ)を自動で読み込みます。

方法PC用スマホ用
A(推奨)python prepare.py obsidian.asar で obsidian/ と一覧 ow-files.json を作るpython prepare.py public.zip で obsidian-mobile/ と一覧 ow-files.json を作る
B(手軽)obsidian.asar を obsidian-web-static/ に置くobsidian-mobile.zip を obsidian-web-static/ に置く
C何も置かず、ランチャーの「asar / モバイル版zipを手動で選ぶ」から指定する

AとBは初回アクセス時に自動で読み込まれます(同じ端末向けに両方あればA優先。片方の種類しか無ければどの端末でもそれを使います)。?ui=mobile / ?ui=desktop をURLに付けると、種類を指定して読み込み直せます。差し替えたあとは「このサイトから読み込み直す」を押してください。

構成と対応ブラウザ

index.html / launcher.js(ランチャー)、sw.js(Service Worker)、app-shim.js(Electron/Node APIの代替)、mobile-shim.js(スマホ版が使うCapacitor APIの代替)、prepare.py(任意)。

フォルダ選択はChrome/Edgeなどのデスクトップ版のみ対応です。Firefox/Safariでは「ブラウザ内お試しvault」だけが使えます(Safariは動かないことがあります)。

obsidian.asar の場所

お使いのOSに合わせて、次のパスから obsidian.asar(または obsidian-1.xx.x.asar)を取得してください。[ユーザー名] は自分のアカウント名に置き換えます。環境によって場所が違うことがあるので、見つからない場合は探してみてください。

自動アップデート版(推奨・最新データ)

C:\Users\[ユーザー名]\AppData\Roaming\obsidian\

通常のインストール先

C:\Users\[ユーザー名]\AppData\Local\Obsidian\resources\obsidian.asar

近道: Win + R を押し、%APPDATA%\obsidian を貼り付けてEnterを押すと、フォルダが直接開きます。

自動アップデート版(推奨・最新データ)

/Users/[ユーザー名]/Library/Application Support/obsidian/

アプリ本体の中

/Applications/Obsidian.app/Contents/Resources/obsidian.asar

近道: Finderで Cmd + Shift + G を押し、~/Library/Application Support/obsidian を貼り付けてEnterを押すと移動できます。

自動アップデート版

/home/[ユーザー名]/.config/obsidian/

スマホ版の public フォルダの場所

スマホ版Obsidianの public フォルダも使えます。IPA / APK から次の場所を取り出してください。AndroidのものでもiOSのものでも、どちらでも動きます。

🍎 iOS

  • IPA md.obsidian/Payload/App.app/public/

🤖 Android

  • APK
    obsidianダウンロードからAPKをダウンロードし、展開 Obsidian-x.x.x/assets/public/

取り出した public フォルダをzipにして使います。静的サイト版は obsidian-mobile.zip として置くか、prepare.py でフォルダにして obsidian-mobile/ として置きます。サーバー版は server.py と同じフォルダに置きます。

共通の制限

  • vaultは、1サーバー(静的版は1ブラウザプロファイル)につき1つです。切り替えUIは動きません。
  • 「既定のアプリで開く」「エクスプローラーで表示」、Webビューア、スクリーンショット系の機能は動きません。
  • ごみ箱は <vault>/.trash になります。
  • app.js は配信時に1箇所だけ置換します(設定画面などを別ウィンドウにしないため)。元のasarは変更しません。
  • コミュニティプラグインやテーマの取得は、サーバー版ではサーバー経由、静的版ではブラウザのCORS制限を受けます。
