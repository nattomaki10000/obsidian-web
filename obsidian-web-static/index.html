obsidian-web

obsidian.asar(サイトに置くか、手動で選択)とPC上のフォルダだけで、ブラウザでObsidianを使えます。サーバーは不要です。

このブラウザではフォルダを直接開けません。
PCのフォルダを使うにはChrome / Edgeなど(File System Access API対応)が必要です。下の「ブラウザ内お試しvault」なら他のブラウザでも試せます(ただしSafariは非対応のことがあります)。

1 Obsidian本体を読み込む (最初の1回だけ)

確認中…
このページと同じ場所に obsidian.asar(または解凍した obsidian/ フォルダ)があれば自動で読み込みます。無い場合は手動で選んでください。スマホ版の APK / IPA から取り出した public フォルダのzip も選べます(その場合は下の「vault」はvaultが並ぶ親フォルダとして使われます)。読み込んだ内容はこのブラウザにだけ保存され、外部へは送信されません。

2 vault(ノートのフォルダ)を選ぶ

未選択
空のフォルダを選ぶとObsidianのサンプルノートが作られます。デスクトップ・書類・ダウンロードなどのフォルダそのものはブラウザの制限で選べないため、その中のサブフォルダを選んでください。お試しvaultはブラウザ内部に保存され、ブラウザのデータ削除で消えます。

3 開く

対応: Chrome / Edge 等のChromium系(デスクトップ)。HTTPSまたは localhost で配信してください。
