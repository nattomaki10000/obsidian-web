Obsidianを、
普通のブラウザで。

自分の obsidian.asar(Obsidian 1.14.4で検証)を、Electronアプリではなくブラウザで開くためのラッパーです。使い方に合わせて、サーバー版・静的サイト版・KV + Pages版の3つがあります。スマホ版Obsidianの public フォルダ(APK / IPA から取り出したもの)にも対応しています。

サーバー版

Electronのメインプロセス相当をPythonで置き換えます。

cd obsidian-web-dynamic
python server.py --asar obsidian.asar --vault ./MyVault

表示された http://localhost:8765/?token=... をブラウザで開きます。

  • 初回だけ asar を .obsidian-web/app に展開します。2回目以降は --asar は不要です。
  • --vault のフォルダがなければ作成し、サンプルノートを入れます。
  • トークンは .obsidian-web/token に保存され、再起動後も同じURLが使えます。
  • スマホ版の public フォルダのzipを server.py と同じフォルダに置く(または --mobile-zip で指定する)と、スマホ・タブレットにはモバイル版、PCにはasar版を同じURLで出し分けます。?ui=mobile / ?ui=desktop で強制もできます。
  • オプション: --port --host --cache --verbose --mobile-zip --allow-host

構成

server.py(静的配信 / 同期IPC / vault内限定のファイルAPI / 画像配信)と、web/shim.js(require('electron') や fs・path などのブラウザ代替)、web/mobile-shim.js(スマホ版用の代替)でできています。

セキュリティ

  • 既定では 127.0.0.1 のみで待ち受けます。Hostヘッダ検証、トークンCookie(SameSite=Strict)、独自ヘッダで、他サイトからの操作を拒否します。
  • ファイル操作はvault内に限定されます(シンボリックリンクでの脱出も拒否)。
外部に公開するとき 0.0.0.0 で公開する場合は、必ずSSHトンネルか、HTTPS付きのリバースプロキシ越しにしてください。

静的サイト版

サーバーなしで、ファイルを置くだけで動きます。本体の読み込みはService Workerとブラウザ内展開、ファイル操作はFile System Access APIで行います。

https://nattomaki10000.github.io/obsidian-web/obsidian-web-static/ で、インストールせずに試せます。

cd obsidian-web-static
python -m http.server 8800      # → http://localhost:8800/

ランチャー(index.html)で、①本体を読み込む → ②フォルダを選ぶ → ③開く、の順に進めます。

Obsidian本体の渡し方

アップロード不要にもできます。ランチャーは、開いた端末に合わせてPCにはデスクトップ版(asar)、スマホ・タブレットにはモバイル版(public フォルダ)を自動で読み込みます。

方法PC用スマホ用
A(推奨)python prepare.py obsidian.asar で obsidian/ と一覧 ow-files.json を作るpython prepare.py public.zip で obsidian-mobile/ と一覧 ow-files.json を作る
B(手軽)obsidian.asar を obsidian-web-static/ に置くobsidian-mobile.zip を obsidian-web-static/ に置く
C何も置かず、ランチャーの「asar / モバイル版zipを手動で選ぶ」から指定する

AとBは初回アクセス時に自動で読み込まれます(同じ端末向けに両方あればA優先。片方の種類しか無ければどの端末でもそれを使います)。?ui=mobile / ?ui=desktop をURLに付けると、種類を指定して読み込み直せます。差し替えたあとは「このサイトから読み込み直す」を押してください。

構成と対応ブラウザ

index.html / launcher.js(ランチャー)、sw.js(Service Worker)、app-shim.js(Electron/Node APIの代替)、mobile-shim.js(スマホ版が使うCapacitor APIの代替)、prepare.py(任意)。

フォルダ選択はChrome/Edgeなどのデスクトップ版のみ対応です。Firefox/Safariでは「ブラウザ内お試しvault」だけが使えます(Safariは動かないことがあります)。

KV + Pages版

静的サイト版を改造して、異なる端末(PC・スマホ・タブレット)で同じvaultを使えるようにした版です。完全無料の範囲で動くように作ってあります。

  • フロント(ランチャー・shim)と、KVを読み書きするAPI(_worker.js)を Cloudflare Pages で動かします。
  • vaultの中身は Workers KV に保存します。
  • 入るにはパスワードが必要です(パスワードはPagesのSecretに置きます)。
  • Obsidian本体(obsidian.asar / モバイル版 public のzip)は、静的サイト版と同じく各端末で読み込む方式です(サイトには置きません)。

アップロードするのは、リポジトリの obsidian-web-kv-pages/obsidian-web-kv-pages.zip です。zipの直下に _worker.js などが並んでいます。

セットアップ(10分ほど)

メニュー名はCloudflareの画面更新で多少変わることがあります。

  1. KV名前空間を作る: ダッシュボード → Workers & Pages → KV → 「Create a namespace」。名前は何でもOKです(例: obsidian-vault)。
  2. Pagesプロジェクトを作る: Workers & Pages → Create → Pages → 「Upload assets」(Direct Upload)。プロジェクト名を決めて obsidian-web-kv-pages.zip をアップロードし、Deployします。
  3. バインディングとパスワードを設定する: 作ったプロジェクトの Settings で、次の2つを Production に追加します。
    • Bindings → KV namespace → 変数名 VAULT_KV、1で作った名前空間を選ぶ
    • Variables and secrets → 種類 Secret → 名前 PASSWORD、値は長めのパスワード(16文字以上を推奨)
    • (任意)Secret SESSION_SECRET を足すと、ログインcookieの署名鍵に混ぜます
  4. もう一度デプロイする: 設定は次のデプロイから反映されます。同じzipをもう一度アップロードしてください。
  5. 発行されたURL(https://〇〇.pages.dev)を開くと、ログイン画面が出ます。
うまく動かないとき PASSWORD (secret) is not set → 手順3のSecretが未設定、または手順4の再デプロイ忘れです。
KV binding VAULT_KV is not configured → バインディング名が VAULT_KV でない、または再デプロイ忘れです。

使い方

各端末で、最初の1回だけ次を行います。

  1. URLを開いてログインします(cookieに30日間保存されます)。
  2. ① Obsidian本体を読み込みます(PC: obsidian.asar / スマホ: APKやIPAから取り出した public のzip)。端末ごとに1回です。
  3. ② 「クラウドvault(KV)を使う」(最初は自動で選ばれます)
  4. ③ 開く

2回目以降は「開く」だけです。モバイル版でも、②のクラウドvaultがそのままvaultとして開きます(PC版と同じ階層で、サブフォルダを作る必要はありません)。同じvaultが全端末で共通に見えます。Obsidian画面の左下に小さく「☁」が出ます。クリックすると今すぐ同期します。別の端末へ切り替える前に「同期済み」を確認してください。

表示意味
☁ 同期済みKVに保存済み
☁ 未保存 N端末内に保存済み、KVへの送信待ち(Nはファイル数)
☁ オフライン / 同期エラー通信できていません。変更は端末内に残り、復帰後に送られます
☁ 書込上限が近いため保留中書き込み節約のため、自動送信を止めています
書き込みのまとめ方(無料枠対策)

KV無料枠は書き込み1日1,000回(UTC 0時にリセット)です。Obsidianは自動保存で頻繁に書くため、次のようにしています。

  • 保存した内容はまず端末内(IndexedDB)に残り、45秒操作が止まるか、最初の変更から3分たつとKVへ送ります。同じファイルを何度保存しても、送るのは最後の1回分です。
  • 作ってすぐ消したファイルや、内容が変わっていない保存は、KVに書きません。
  • タブを閉じる/隠すときにも送ります。送れなかった分は端末内に残っていて、次に開いたときに送ります。
  • この端末の本日の書き込みが400回を超えると送信間隔を5分〜15分に延ばし、900回で自動送信を止めます(☁をクリックすれば送れます)。
  • ☁にマウスを乗せると、この端末の本日の書き込み回数が見えます(他の端末の分は含みません)。
  • 調整したい場合は、開発者ツールで localStorage に秒数を入れます: ow.kv.idle(既定45)、ow.kv.max(既定180)、ow.kv.limit(既定900)。
  • 一覧取得(list)にも1日1,000回の別枠があります。開いた時と、画面を触っている間の10分おきに行うだけなので、通常は足ります(30分操作がなければ自動更新を止めます)。
制限・注意
  • 同じノートを2台で同時に編集しないでください。後から送った方が勝ちます(自動マージはしません)。切り替えるときは「同期済み」を確認してからにしてください。
  • 他の端末の変更が見えるまで、最大10分ほどかかります(☁クリックで即時)。KVの仕様上、反映に最大1分ほどの遅れもあります。
  • 1ファイル25MiBまで(KVの上限)。超える添付は保存できません。
  • パスの長さは500バイトまで(日本語は1文字3バイトなので、約160文字)。
  • フォルダの移動・リネームは、中のファイル1つずつが書き込みになります。大きなフォルダを動かすと無料枠を使い切ることがあります。
  • 全リクエストがWorkerを通るため、Workers無料枠(1日10万リクエスト)に数えられます。個人利用なら十分です。
  • Obsidian本体を差し替えたり、この版に更新したあとは、ランチャーで本体を読み込み直してください。
セキュリティ
  • パスワードを知らない人には、ログイン画面以外(コードもvaultも)返しません。vaultはAPIを通してしか読み書きできません。
  • ログインcookieは HttpOnly / Secure / SameSite=Strict、署名つきで30日有効です。パスワード(Secret)を変えて再デプロイすると、全端末が自動でログアウトします。
  • パスワード照合は定数時間で行い、失敗すると1秒待たせます。ただし回数制限はありません。長いパスワードを使ってください。
  • 書き込み系APIは、独自ヘッダと送信元の確認でCSRFを防いでいます。
  • vaultの中身は暗号化せずにKVへ保存されます(Cloudflare側の保存時暗号化のみ)。端末間の暗号化(E2E)が必要なら、別途改造が必要です。
  • Obsidian本体はサイトに含まれません。再配布にならないよう、zipやasarをサイトに置かないでください。

くわしくは、リポジトリの obsidian-web-kv-pages/README.md を見てください。

obsidian.asar の場所

お使いのOSに合わせて、次のパスから obsidian.asar(または obsidian-1.xx.x.asar)を取得してください。[ユーザー名] は自分のアカウント名に置き換えます。環境によって場所が違うことがあるので、見つからない場合は探してみてください。

自動アップデート版(推奨・最新データ)

C:\Users\[ユーザー名]\AppData\Roaming\obsidian\

通常のインストール先

C:\Users\[ユーザー名]\AppData\Local\Obsidian\resources\obsidian.asar

近道: Win + R を押し、%APPDATA%\obsidian を貼り付けてEnterを押すと、フォルダが直接開きます。

自動アップデート版(推奨・最新データ)

/Users/[ユーザー名]/Library/Application Support/obsidian/

アプリ本体の中

/Applications/Obsidian.app/Contents/Resources/obsidian.asar

近道: Finderで Cmd + Shift + G を押し、~/Library/Application Support/obsidian を貼り付けてEnterを押すと移動できます。

自動アップデート版

/home/[ユーザー名]/.config/obsidian/

スマホ版の public フォルダの場所

スマホ版Obsidianの public フォルダも使えます。IPA / APK から次の場所を取り出してください。AndroidのものでもiOSのものでも、どちらでも動きます。

🍎 iOS

  • IPA md.obsidian/Payload/App.app/public/

🤖 Android

  • APK
    obsidianダウンロードからAPKをダウンロードし、展開 Obsidian-x.x.x/assets/public/

取り出した public フォルダをzipにして使います。静的サイト版は obsidian-mobile.zip として置くか、prepare.py でフォルダにして obsidian-mobile/ として置きます。サーバー版は server.py と同じフォルダに置きます。KV + Pages版は、各端末のランチャーから手動で読み込みます。

共通の制限

  • vaultは、1サーバー(静的版・KV版は1ブラウザプロファイル)につき1つです。切り替えUIは動きません。
  • 「既定のアプリで開く」「エクスプローラーで表示」、Webビューア、スクリーンショット系の機能は動きません。
  • ごみ箱は <vault>/.trash になります。
  • app.js は配信時に1箇所だけ置換します(設定画面などを別ウィンドウにしないため)。元のasarは変更しません。
  • コミュニティプラグインやテーマの取得は、サーバー版ではサーバー経由、静的版・KV版ではブラウザのCORS制限を受けます。
